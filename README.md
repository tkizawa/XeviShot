# RETRO SHOOTER (XeviShot) 遊び方説明書

このゲームは、自機「Xenon-Ray (ゼノン・レイ)」を操り、敵の組織「Galdora（ガルドロワ帝国）」の空中の敵と地上の敵を撃ち分けながら進む、縦スクロールのレトロ風シューティングゲームです。

## 🚀 起動方法

### 動作環境
* .NET 10 (Windows x64) または スタンドアロン実行ファイル

### 実行手順
- **スタンドアロン実行**: `.\Installer\XeviShot_v1.0.0.0_win-x64.exe` を直接ダブルクリックで起動
- **dotnet CLI で実行**:
  ```bash
  dotnet run -c Release
  ```

## 🎮 操作方法

### キーボード操作
* **移動**: `↑` `↓` `←` `→` （矢印キー）
* **Zapper（対空攻撃）**: `Z` キー
  * 空中にいる敵「Zoldas（ゾルダス）」（赤い機体）を攻撃します。
  * **レーザー**: レーザーカプセル（L）取得時に発射可能。敵を貫通し、射線軸線上（縦一列）の空中敵を一網打尽にします。
  * **波動砲**: `Z` キーを約1秒長押ししてパワーを溜め、離すと強力な「波動砲」を発射します。波動砲は敵の弾をかき消すこともできます。
  * **拡散波動砲**: `Z` キーをさらに長く（約10秒）長押ししてパワーを限界まで溜め、離すと広範囲を攻撃する「拡散波動砲」を発射します。これも敵の弾をかき消すことができます。
* **Blaster（対地攻撃）**: `X` キー
  * 地上にいる敵（紫の四角形）を攻撃します。自機の前方にある赤い照準（レティクル）の位置に爆弾を投下します。
* **同時押し**: `C` キー
  * Zapper（対空）とBlaster（対地）の両方を同時に使用できます（長押しでチャージも可能）。

### ゲームパッド（コントローラー）操作
* **移動**: 左スティック
* **Zapper（対空攻撃・チャージ）**: `A` ボタン
* **Blaster（対地攻撃）**: `B` ボタン

## 👾 敵キャラクターと得点

敵の組織「Galdora（ガルドロワ帝国）」の兵器と得点一覧です。

* **空中敵「Zoldas（ゾルダス）」（赤色）**: 100点
  * 空を飛び、自機に向かって弾を撃ってきます。「Zapper」や「レーザー」、「波動砲」「拡散波動砲」で倒せます。
* **空中敵「Phaeon（フェイオン）」（黄色）**: 500点
  * ゲーム開始1分後から出現する高速一撃離脱型の敵機。急降下して自機を正確に狙う「自機狙い弾」を1発放ったのち、上空へ加速して逃げ去ります。
* **地上敵（紫色）**: 300点
  * 地上に配置されており、自機の爆弾でのみ破壊可能です。赤い照準を合わせて「Blaster」を投下してください。
* **敵の弾の破壊**: 10点
  * 波動砲や拡散波動砲で敵の弾をかき消すと、1発につき10点のスコアが入ります。

## 🎁 アイテム

敵を撃破した際、以下のアイテムが落ちてくることがあります。カプセルの中央には識別用のアルファベットが表示されます。

* **🛡️ シールドカプセル（水色 / 表示: S）** - *出現確率: 10%*
  * 取得すると自機の周りにシールドが展開され、**最大5回まで**敵本体や敵の弾との衝突を防いでくれます。
  * シールドの残り耐久回数は、自機の周りを回転する白い点の数で確認できます。
  * シールド展開中に新たなシールドカプセルを取得すると、耐久回数が再び5回まで全回復します。

* **⚔️ ウェポンカプセル（赤色 / 表示: W）** - *出現確率: 10%*
  * 取得すると自機の通常攻撃（Zapper）がパワーアップし、レベル（最大3）に応じて複数発の弾を同時に発射できるようになります。
  * **レーザー発射中（レーザーモード）にこのカプセルを取得すると、レーザー状態が解除されて「WEAPON LEVEL 1」にリセットされます。**
  * 被弾してミス（残機が減少）になると、初期状態（1発）に戻ってしまいます。

* **⚡ レーザーカプセル（緑色 / 表示: L）** - *出現確率: 10%*
  * 取得すると、通常攻撃（Zapper）が敵を貫通する強力な**レーザー**に変化します。
  * **通常弾モードからこのカプセルを取得すると、通常弾の「WEAPON LEVEL」が 1 にリセットされます。**
  * レーザーは射線軸線上（縦一列）のすべての空中敵を貫通して一撃で撃破します。
  * ウェポンカプセル（W）を取得すると、レーザーは解除されて通常攻撃（レベル1）に戻ります。
  * 被弾してミス（残機が減少）になると、レーザー状態は解除されます。

## ⚠️ ルール・ゲームクリア・ゲームオーバー

* ゲーム開始時、残機（LIVES）は3つあります。
* シールドがない状態で敵の弾や敵本体にぶつかると、残機が1つ減ります。
* 残機が0の状態で撃墜されるとゲームオーバーとなります。
* **ボス出現とステージクリア**:
  * プレイ開始から**3分経過**すると、通常の敵の出現が停止し、**専用BGM（不気味なボス曲）**とともに強力な**ボスキャラ**が出現します。
  * 画面上部に表示されるボスのHPを削り、ボスを撃破すると**ステージクリア**となります。
  * ステージクリア画面では最終スコアが表示され、いずれかのキーまたはボタンを押すと次のステージを開始できます。この際、**獲得したスコアはリセットされずに引き継がれます**。（※ゲームオーバー時はスコアがリセットされます）
* 限界までスコアを稼ぎ、ステージクリアとハイスコアを目指しましょう！
